# cadapt 0.12.0

This release adds the mid profile, adaptive and reversible-transform options,
folder metadata support, memory tiers and segmented operation. It also adds
release packaging and validation tools. The [changelog](../../CHANGELOG.md)
records fixes, including filesystem staging and resource-limit protections.

**Upgrading from 0.11.0 requires container migration.** Decode its version 13–15
files with 0.11.0 before replacing that binary, or keep both installations.

## Install

Verify downloaded files against SHA256SUMS from the release page. Checksums
provide integrity against that manifest; they are not a signature.
On Linux, a platform tarball can be installed under a user prefix:

```sh
sha256sum -c SHA256SUMS --ignore-missing
tar -xzf cadapt-0.12.0-linux-x86_64.tar.gz
mkdir -p "$HOME/.local"
cp -R cadapt-0.12.0-linux-x86_64/bin cadapt-0.12.0-linux-x86_64/lib \
      cadapt-0.12.0-linux-x86_64/include cadapt-0.12.0-linux-x86_64/share "$HOME/.local/"
"$HOME/.local/bin/cadapt" --version
```

The installed paths are `bin/cadapt`, `lib/libadapt.a`, `include/adapt.h` and
`share/man/man1/cadapt.1`. Add the prefix's bin directory to PATH. The archive
also includes license, support/security policy and provenance files.
Use the matching platform archive on macOS; the configured platform matrix is
in [SUPPORT.md](../../SUPPORT.md). Windows is not a validated release platform.

Building a source tarball requires a C99 compiler and Make:

```sh
tar -xzf cadapt-0.12.0-src.tar.gz
cd cadapt-0.12.0
make
make install PREFIX="$HOME/.local"
```

Use DESTDIR for staged installation. Python and benchmark dependencies are
needed to run the full validation suite, not to build the codec.

## Use

```sh
cadapt encode report.pdf
cadapt decode report.pdf.adpt -o report-copy.pdf
cadapt encode photos/ -o photos.adpt --verify
cadapt decode photos.adpt -o photos-copy
cadapt encode records.csv --max -6
cadapt info records.csv.adpt
```

The default profile is normal and the default memory tier is -9. The fast,
mid and max profiles choose different predictors; performance depends on the
input. Encoder proof is off unless --verify is supplied. Decode uses the
recorded model; --max-memory and --max-output impose optional resource caps.
[README.md](../../README.md) and the [manual](../../adpat/c/cadapt.1) describe all options.

--threads creates independent segments. The requested count and segment size
can change compressed bytes; scheduling identical segments across different
available workers does not. Named outputs are staged, while stdout can receive
a prefix before a final error. See [archive restoration](../../adpat/c/ARCHIVE.md)
for filesystem portability and publication failure behavior.

## Compatibility

The decoder supports container versions 19 to 85, excluding 55, 59, 60, 73
and 74. Archive versions 1–4 are readable; the CLI writes version 4.
The supported formats have the forward compatibility commitment defined in
[SUPPORT.md](../../SUPPORT.md). Unknown numbers are rejected.

Encoder format selection depends on profile, transform, metadata and sizing
policy; `ADAPT_VERSIONS` in [adapt.h](../../adpat/c/adapt.h) defines the exact
layouts. C callers must rebuild against the matching header and static library
because sizing/statistics structs gained fields. Public API ownership, callback,
thread and error contracts are documented in the header and
[examples](../../adpat/c/examples/).

## Upgrading from 0.11.0

Before upgrading, decode retained version 13–15 containers with cadapt 0.11.0,
or keep its executable separately. That release has no install target. From a
Git checkout containing the v0.11.0 tag, build an isolated copy:

```sh
legacy_dir=$(mktemp -d)
git archive v0.11.0 adpat/c | tar -x -C "$legacy_dir"
make -C "$legacy_dir/adpat/c"
"$legacy_dir/adpat/c/build/cadapt" decode old.adpt -o restored.bin
```

`cadapt info` reports a container's version. Keep the original containers until
decoded content has been verified.
Installing 0.12.0 under the same prefix replaces the executable, static library,
header and manual; it does not convert stored containers.
